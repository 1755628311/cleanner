Tunduk pada kepatuhan Anda terhadap Perjanjian ini, kami memberikan lisensi terbatas, non-eksklusif, tidak dapat dialihkan, dan dapat dicabut untuk menginstal dan menggunakan Aplikasi di perangkat Android yang Anda miliki atau kendalikan, semata-mata untuk keperluan pribadi dan non-komersial.

Anda dapat menggunakan Aplikasi untuk:

  • Melihat penggunaan penyimpanan dan menerima rekomendasi pembersihan

  • Mengelola file media dan menggunakan alat optimasi jika didukung
