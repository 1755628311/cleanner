5. Izin

Aplikasi meminta izin hanya jika diperlukan untuk fitur tertentu. Anda dapat memberikan atau menolak izin di pengaturan sistem Android. Menolak izin dapat membatasi fungsionalitas terkait.

  • Akses penyimpanan / media (READ_EXTERNAL_STORAGE, READ_MEDIA_*) — memindai dan membersihkan cache, file sementara, dan konten media
  • Akses semua file (MANAGE_EXTERNAL_STORAGE) — pembersihan mendalam saat scoped storage membatasi akses biasa
  • Akses penggunaan (PACKAGE_USAGE_STATS) — menampilkan statistik penggunaan dan cache per aplikasi
  • Jaringan (ACCESS_NETWORK_STATE, INTERNET) — memeriksa konektivitas; memuat Kebijakan Privasi dan Ketentuan dalam aplikasi melalui WebView
  • Status Wi‑Fi (ACCESS_WIFI_STATE) — menampilkan informasi terkait Wi‑Fi di layar Info Sistem
  • Permintaan hapus paket (REQUEST_DELETE_PACKAGES) — membantu menghapus instalasi aplikasi yang Anda pilih untuk dihapus
  • Lokasi (ACCESS_FINE_LOCATION, ACCESS_COARSE_LOCATION) — fitur Info Sistem dan Tips Keamanan; tidak digunakan untuk periklanan atau pelacakan yang tidak terkait
  • Bluetooth (BLUETOOTH, BLUETOOTH_CONNECT) — menampilkan status Bluetooth aktif/nonaktif di layar Info Sistem; tidak digunakan untuk periklanan atau pelacakan yang tidak terkait

6. Pemrosesan Lokal

Secara default, hasil pemindaian dan pembersihan diproses dan ditampilkan di perangkat Anda. Kami merancang Aplikasi agar fungsi pembersihan dan analisis inti berjalan tanpa mengunggah isi file Anda ke server kami.
